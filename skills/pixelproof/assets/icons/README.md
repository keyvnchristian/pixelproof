# Starter sprite

`starter-sprite.svg` contains 63 line icons in one style: a 24×24 viewBox, `fill: none`, and stroke from `.icon`.

How to use it:

1. Copy it to `slices/sprite.svg`.
2. Delete the icons you don't need.
3. Redraw or add icons so they match the reference's measured stroke width, caps, and corner style.
